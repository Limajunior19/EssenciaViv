# EssenciaViva
Nesta aplicação, conforme solicitado, foram elaboradas três telas: a Tela Inicial, a Tela de Boas-Vindas e a Tela de Serviços. Entre essas telas, foram adotadas interações que permitem uma navegação fluida.

Na Tela Inicial, há uma apresentação breve da aplicação, que inclui botões direcionados para as outras telas. O botão "Começar Agora" redireciona para a Tela de Boas-Vindas, que também possui uma opção para retornar à tela anterior. O segundo botão, "Ir para Serviços", leva à terceira tela, onde são apresentados os serviços disponíveis com botões interativos para tornar a navegação mais acessível.

Para a criação e identificação do código, utilizamos materiais de apoio disponíveis em docs.flutter.dev , que foram fundamentais na implementação, especialmente no que diz respeito aos botões e às interações entre as telas.

Além disso, utilizei o BlackBox para realizar primeiramente a correção do código e identificar erros que não eram visíveis à vista. O DartPad foi contratado para compilar o código e verificar seu funcionamento conforme planejado.
